# A Loan has its own place next to Applications

Mellon is one Buyer's portal. The sidebar has three destinations: Dashboard, Active loans, and My applications.

Dashboard summarizes this Buyer's book: loan count, combined balance, principal paid, the next debit, and progress across the loans. Active loans is the list of loans Substrate has funded for this Buyer. My applications stays the Mellon list of requests that are not yet a loan, plus the funded row. View loan on a funded row opens that loan.

The earlier alternative was no loans destination at all, only the funded row. That hid the servicing home inside the application list.
