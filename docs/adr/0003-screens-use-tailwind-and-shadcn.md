# Screens use Tailwind and shadcn

The first cut drew Mellon with one hand-written stylesheet and no component library, so a loan screen could not drift into a kit look. That sheet became the drift: every screen recopied the same card, pill, and button. Tailwind utilities plus shadcn's button, card, badge, input, and label hold those pieces once. The Mellon frame stays: white page, hairline cards, quiet status pills, support rail, dark footer. Keeping the stylesheet was the alternative, and so was shadcn's default theme, which would stop looking like Mellon.
