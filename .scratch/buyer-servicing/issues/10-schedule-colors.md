# 10: Color paid, expected, and failed installments

**What to build:** On a Loan, a paid month is green, an expected month is yellow, and a failed month is red. The Buyer can tell the states apart without reading only the words.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] A posted installment is green and labeled paid
- [x] An upcoming installment is yellow and labeled expected
- [x] A returned installment is red and labeled failed
- [x] Upcoming and history both use these colors

## Comments

The Dane fixtures have no returned installment. The red state is on the Loan screen for a returned ledger entry.
